Nexara 0.1.2 refreshes dependencies to resolve known security vulnerabilities while preserving the existing public API.

- Updated QUIC, TLS, certificate trust, and crossbeam dependencies to patched releases.
- Resolved the anyhow downcast unsoundness advisory and replaced a yanked chacha20 release.
- Updated all 14 Rust crates and the JavaScript SDK version to 0.1.2.
- Repaired dependency-policy validation, documented maintenance-only exceptions for the optional sled backend, and allowed the certificate bundle data license.
- Enabled security checks on pushes to the default branch and made release validation check the current workspace version.

Upgrade Rust dependencies to `0.1.2` and refresh your lockfile with `cargo update`. Existing lockfiles must be refreshed to pick up transitive dependency fixes.

The optional sled storage backend retains upstream maintenance warnings for fxhash and instant. No known vulnerabilities remain in the release lockfile at validation time.
